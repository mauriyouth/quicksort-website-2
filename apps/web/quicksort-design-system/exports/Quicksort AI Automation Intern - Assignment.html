The assignment

AI CV Analyzer Agent

Build and deploy an AI application using Next.js, Vercel AI SDK, and Supabase.

Your objective

Create a web application where a user uploads a CV and pastes a job description. The AI agent analyzes the candidate against the role, displays a structured result, and stores the analysis in Supabase.

Application flow

Upload CV→Enter job description→Analyze CV→Display results→Save to Supabase

What the analysis must include

  • Candidate overview: name, concise summary, and years of experience.
  • Skills and technologies: key skills detected, relevant technologies, and skills that match the job description.
  • Fit assessment: strengths, missing skills, and a match score out of 100.
  • Short recommendation: Strong Match / Potential Match / Not a Match.

Keep the interface simple

Include a CV upload control, a job description text area, and an Analyze CV button. Show the structured analysis, a prominent match score, detected skills, and missing skills. No complex UI is required.

Required technology

Next.jsfor the web application
Vercel AI SDKto build the CV Analyzer Agent
Supabasefor database persistence
Vercelfor the live deployment

The goal: demonstrate how quickly you can take an AI application from idea to production using AI coding tools, Vercel, and Supabase.

  • Use Vercel CLI to configure and deploy the application.
  • Use Supabase CLI to create/link the project, create database migrations and required tables, push database changes, and configure the project.

Persist results in Supabase

Store candidate name, CV file reference, job description, match score, skills detected, missing skills, AI recommendation, full analysis, and created date. Bonus: store uploaded CV files in Supabase Storage.
